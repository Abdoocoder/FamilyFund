# Module 3: Audience & Niche

## Raw
- PRODUCT.md specifies two audiences
- Primary: Treasurer (المحاسب) — operates the app weekly, needs speed and accuracy
- Secondary: Family members — check standing periodically, need clarity and transparency
- Jordanian families, Arabic-speaking, RTL-native
- Fund size: ~48 members, could scale to 20-100

## Synthesis

**Primary ICP — The Treasurer:**
- Manages family finances
- Not technical — needs a tool that's faster and more reliable than Excel
- Primary workflow: toggling 48 payment cells in a session
- Pain: Excel is error-prone, unclear, slow; family asks "did I pay?" constantly

**Secondary ICP — Family Members:**
- Any age, any technical skill
- Need to check their standing instantly, without asking the Treasurer
- Want reassurance that the system is fair and transparent
- Pain: relying on the Treasurer to check for them, suspicion about fairness

**Niche:**
Hyper-local: Jordanian/Jordanian-diaspora families running صندوق الجمعية. This is a culturally specific practice — the app is built for it, not adapted to it.
